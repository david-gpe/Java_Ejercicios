# ☕ Java Practice – Ejercicios y Fundamentos

## 🧠 Descripción

Repositorio de práctica enfocado en el aprendizaje y refuerzo de conceptos fundamentales de **Java**.

Incluye una colección de ejercicios que cubren desde lógica básica hasta estructuras de datos y programación orientada a objetos.

---

## 🎯 Objetivo

Desarrollar habilidades en Java mediante la resolución de problemas prácticos y la implementación de conceptos clave.

---

## 📚 Contenido

Los ejercicios abarcan:

### 🟢 Fundamentos

* Variables y tipos de datos
* Estructuras de control (`if`, `switch`)
* Ciclos (`for`, `while`)

---

### 🟡 Intermedio

* Métodos y funciones
* Arreglos y colecciones
* Manejo de cadenas

---

### 🔴 Programación Orientada a Objetos

* Clases y objetos
* Encapsulamiento
* Herencia y polimorfismo
